# Welcome illustrations

The passkey-created welcome screen introduces four benefits in one glance. Its four small illustrations use the Midnight blue, white, and cool grey palette. They sit above short, plain-language copy in a four-column desktop layout that becomes two columns on phones. The layout and artwork are independent of authentication state or network data.

| Asset | Visual brief |
| --- | --- |
| `identity.webp` | A simple white Passport booklet with a cobalt edge and a keyhole/fingerprint motif. |
| `name.webp` | A cobalt nameplate moving in front of faint address lines, representing a memorable `.night` name. |
| `fees.webp` | A cobalt sponsor arc sheltering a silver token, representing sponsored setup without implying a balance. |
| `privacy.webp` | A cobalt approval tick partly protected by layered white panels, representing selective disclosure. |

The source images were generated as transparent, isolated product illustrations using the prompt set above, with instructions for no text, no background scene, no decorative particles, consistent front-facing 3D paper-and-enamel treatment, soft shadows, and generous transparent margins. The web assets are resized, compressed WebP derivatives; source PNGs are retained outside the repository in the local generated-image archive.

The page retains the existing `onChooseName` action. Theme changes affect the card surfaces, not the artwork, so both light and dark modes use the same four files. Motion remains limited to the button hover state and honours reduced-motion preference.
